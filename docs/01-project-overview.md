# Project Overview

## Overview

This repository documents a wireless communications engineering project developed as part of the Telecommunications Engineering degree. The project combines practical laboratory deployments with mathematical simulations to analyze wireless network performance across different communication technologies.

The work is divided into three main technical areas:

- IEEE 802.11 wireless network configuration and security
- LoRaWAN IoT infrastructure deployment and performance analysis
- GSM cellular network planning through frequency reuse simulations

The project combines laboratory experimentation, protocol analysis, wireless performance evaluation and mathematical modeling using industry-standard networking tools.

---

# Objectives

The project was developed to achieve the following engineering objectives:

- Deploy and configure IEEE 802.11 wireless networks.
- Analyze wireless traffic using packet capture tools.
- Design and evaluate a complete LoRaWAN IoT architecture.
- Measure wireless communication quality using RSSI and SNR metrics.
- Simulate GSM cellular networks under different frequency reuse factors.
- Evaluate co-channel interference and network capacity.
- Apply mathematical models to optimize wireless network performance.
